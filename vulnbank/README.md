## Vulnbank

## Overview

## VulnBank adalah aplikasi perbankan yang sengaja dibuat rentan, yang digunakan untuk berlatih uji penetrasi aplikasi web.

## Scope

- Authentication
- Authorization
- Business Logic
- File Upload

---

## Methodology

- Recon
- Vulnerability Identification
- Exploitation
- Risk Assessment
- Remediation
